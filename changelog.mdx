## Recent Platform Updates

Stay informed about the latest releases for Ravi Kumar's comics platform. Each update includes new features like custom comics, library enhancements, and performance improvements. Review the details below to understand changes and upgrade smoothly.

<Callout kind="info">
  Bookmark this page and subscribe to notifications for automatic alerts on new releases.

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "improvement"]}>

## New Features

- Added Psychology and Technology comic categories for expanded learning paths.
- Introduced print-on-demand customization: personalize comics with your child's name and photo as the lead character.
- New parent dashboard to track reading progress and EQ development metrics.

## Improvements

- Enhanced library search with filters for age, topic (Science, Business, History), and difficulty.
- Optimized mobile experience for seamless reading on tablets and phones.

## Bug Fixes

- Fixed occasional crashes during comic downloads.
- Resolved sharing issues on social platforms.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "bugfix"]}>

## New Features

- Launched "For Parents" section with guides on using comics for business and science education.
- Integrated EQ-building activities tied to each comic storyline.

## Bug Fixes

- Corrected authentication glitches during sign-in on Safari browsers.

</Update>

## Upgrading to the Latest Version

Follow these steps to migrate your integration or app to v1.2.0.

<Steps>
  <Step title="Backup Your Data" icon="database">

  Export your library favorites and custom comics.

  ```
  # Use the export API
  curl -H "Authorization: Bearer YOUR_TOKEN" https://api.example.com/export
  ```

  </Step>
  <Step title="Update Dependencies" icon="package">

  Refresh your client libraries.

  <Tabs>
    <Tab title="npm" icon="package">
````bash
npm update ravi-kumar-sdk@latest
````
    </Tab>
    <Tab title="yarn" icon="package">
````bash
yarn upgrade ravi-kumar-sdk@latest
````
    </Tab>
  </Tabs>

  </Step>
  <Step title="Test Customization" icon="edit-3">

  Verify personalized comics render correctly with new photo upload feature.

  </Step>
  <Step title="Deploy" icon="upload">

  Push changes and monitor for errors.

  </Step>
</Steps>

<Callout kind="tip">
  Test in staging first. Use `https://api.example.com/staging` for previews.
</Callout>
